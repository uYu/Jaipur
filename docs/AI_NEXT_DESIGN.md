# 斋普尔下一版 AI：信息集搜索、行动预测与特权训练

设计日期：2026-09-24。状态：已实现离线初始化、fresh PPO、规则后验与单历史树搜索原型；首轮实战未达到替换旧模型门槛。实验结果见 [information-pilot](../analysis/information-pilot-2026-09-24/README.md)。目标：在 **每手 1,000 ms 完整决策预算**下，提高完整比赛胜率，并保留可在 CPU/Wasm 上运行的部署路径。

推荐方案：**公开信息策略／价值网络 + 受规则约束的隐藏状态后验 + 单棵历史树搜索；训练时使用额外隐藏信息训练 critic。** 这是针对斋普尔的组合方案，借鉴 AP-MCTS 的对手行动预测、POMCP 的历史树与根状态采样、PerfectDou 的训练与执行信息分离。它不是任何一篇论文的直接复现，也不预设一定强于现有 AI。

## 1. 研究依据与取舍

贴文中的“强于 DouZero”等结论来自各自斗地主实验；不同规则、对手、训练量和指标不能拼成统一排名。AlphaDou 的叫牌目标、农民合作奖励分解都不属于本项目双人斋普尔的核心问题。本设计重点研究上面六项，不将其余方法的效果视为已证实可迁移。

## 2. 目标统一为整场胜负

固定玩家 p 的终局标签为 `z_p = +1（先得两枚印章）/-1（对方先得两枚）`；主价值 `V(I_p)` 预测该标签的期望，胜率为 `(V+1)/2`。搜索边 Q、叶子 V、训练回报和评测都使用此口径，折扣 gamma=1。

本轮分差和本轮胜负可作辅助监督，不与整场价值直接加权选行动。轮末未决出整场胜负时继续采样下一轮发牌，直到下一次玩家 p 的决策，再调用整场价值网络。下一轮先手按引擎规则确定（败方先手；平局轮换），不能统一假定轮流先手。若工程上以后增加轮末边界价值，应专门训练该类型状态后再替代采样。

比赛中某轮平局不会立刻结束整场；轮次不能假定最多三轮。新编码保留印章、先手和阶段，轮次作有界或对数编码，避免延用 `round/3` 的隐含范围假设。

## 3. 信息表示：先建立不能泄露的接口

部署入口为 `decide(PlayerView, PublicEvent[], budgetMs)`，不接收真实 `State`、seed、rng、真实牌堆顺序或对手私有奖励面值。

- `PublicEvent` 存行动者、行动类别、取／付货物数量、骆驼数量、出售数量、公开市场补牌、奖励档位与张数、轮末公开结算。必须把现有索引式 `Event.exchange.hand` 转为公开展示的货物种类，不能将隐藏手牌数组索引送入网络。
- `PlayerView(p)` 存 p 的手牌和奖励筹码、公开货物分、市场、牌堆剩余张数、对方手牌数量、可知骆驼数量、筹码堆、印章、先手和当前行动者。对手隐藏奖励的分布要建模，不能只猜货物手牌。
- 历史编码只消费已发生的公开事件；自己的当前私有信息单独编码。完整历史身份用于树节点相等性，不能仅用 GRU 向量作树键。
- 训练回放可使用真实完整状态重建标签，但特权字段通过独立的数据结构提供。现有 `observe()` 与 belief 回放依赖 seed 重放的实现不能直接复制到搜索路径；应改为消费脱敏公开事件。

网络可以看到当前玩家知道的手牌；“公开信息网络”指只使用该玩家合法可见的信息，并非把其自己的私有手牌也删掉。

## 4. 后验：规则约束负责可行性，模型负责行为证据

隐藏状态 X 包含对手手牌、双方不可见奖励筹码的分配、剩余牌堆和奖励堆的组成，以及更新所需的历史轨迹。用计数表示同类牌，不用真实未来顺序。模型假设的未来补牌和奖励抽取都按剩余组成无放回抽样。

首先复用 `hand-belief.ts` 的牌数守恒、公开取付、卖牌和补牌证据，重构成不依赖完整真实状态的版本。基础分布 `B0` 关闭旧的 `takePreference=0.75` 行为偏好，避免与新行动似然重复使用同一证据。对手最多七张货物手牌使六类计数支持集可控；奖励面值联合分配则适合用带权粒子表示。

对手实际行动 a 出现后，按每个可行粒子的对手可见信息计算行动概率：

```text
w'_j ∝ w_j × μ(a | I_opp(X_j)) × Pr(本次公开/我方可见结果 | X_j, a)
```

随后应用合法转移。非法粒子权重为零。我方自己选择的行动是干预，不乘 `π(a|I_own)`；只用行动后观察到的补牌／奖励等结果更新后验。模型拟合的温度与少量均匀平滑在独立验证集校准，避免一手不常见操作令后验崩溃。

初始粒子数试验档为 32/128/256；ESS=`1/sum(w_j²)` 过低时重采样，并从满足**全部既有观察**的约束分布补充轨迹。若权重全灭，回到同一历史下的规则可行后验并记录异常，不能重新均匀发牌抹去历史。真实过滤与树内 root-sampling 区分：真实观察更新粒子权重；树内由生成器抽样发生的对手行动不再重复乘其似然。

隐藏牌辅助头预测每种货物数量（0…7），监督来自训练模拟器。它用于校准诊断和后续 proposal 加速；首版不把六个独立边缘分布直接当联合手牌采样，也不把“已看完整历史的神经 posterior”再乘完整历史似然。以后用其生成 proposal 时，须在受约束联合分布上归一化并做目标／proposal 权重修正。

## 5. 网络结构与标签

首版建议公共事件 GRU 64 单元，状态 MLP 128 单元；状态上下文每个节点只编码一次，合法行动沿用 24 维数量编码，经共享小行动编码层和 64 单元评分头批量处理。下列大小是待测起点，不是性能结论。

| 模块 | 输入 | 输出与训练标签 | 部署用途 |
| --- | --- | --- | --- |
| 策略 π | 玩家可见状态、公开历史、合法行动 | 合法行动 logits；先行为克隆，后 PPO 或搜索分布监督 | 我方搜索先验、无搜索行动 |
| 价值 V | 同一玩家可见状态、公开历史 | `tanh` 标量；该玩家整场回报 | 新叶子估值 |
| 对手行为 μ | 被建模玩家的可见状态、公开历史、其合法行动 | 实际行动交叉熵；包含历史版本、搜索代理和基线的样本 | 隐状态过滤的行动似然、模拟对手行动 |
| 手牌辅助头 B | 观察者可见状态与公开历史 | 六种手牌数量分布；真实隐藏手牌作监督 | 校准诊断，后续可作 proposal |
| 特权 critic C | actor 信息 + 当前双方隐藏手牌／奖励分配 | 同一实际行为策略下的整场价值 | 仅训练时计算 advantage |

μ 的样本里可以使用模拟器获取该行动者自己的手牌，但输入必须屏蔽其不知道的另一方手牌。搜索时用粒子的假设手牌构造 `I_opp`；不能把根玩家真实私有手牌塞给对手网络。公共 GRU 可共享，策略与行为预测头分开；π 的“自己应怎么走”和 μ 的“对方会怎么走”不强制相同。

C 不读取真实未来牌序或未来 RNG。它估计的是同一受限策略的条件回报，不是全知玩家最优值。首版 C 使用独立网络，actor 始终只消费 PlayerView，不对每个隐藏世界的全知最优动作做硬蒸馏。公开 V 首版以真实终局标签为主；critic 蒸馏仅作后续单独消融，检查公开 V 的校准。

现有 738/612 是 Q 网络，其权重不直接视为新策略／价值模型；可以复用已存轨迹和可兼容的特征。旧轨迹没有根访问分布时，只有执行动作的行为克隆标签，不能伪称 MCTS policy target。

## 6. 搜索：以我方决策到下一次我方决策为一步

每次真实决策只建一棵树。节点标识是**根玩家自己的行动—观察历史**，包括其私有奖励观察与下一轮自己的发牌；同样可见历史下，不同对手手牌样本共享 N/W/Q。每次 simulation 从根后验重新抽样一个 X；根玩家未来的行动选择由该共享节点决定。

对手行动与补牌作为环境转移：按 `μ(a|I_opp(X))` 抽样，执行规则，再抽样机会事件；一直走到根玩家下一次可行动或整场终局。因此每个树中决策节点都是根玩家行动，Q 始终从根玩家视角回传，不在对手回合误翻符号。

```text
DECIDE(I, belief, 1000ms):
    deadline = 请求开始时刻 + 1000ms
    更新真实后验；计算根合法行动、π 和 V
    T = 一个根玩家历史树
    while 剩余时间足够完成一次受限模拟并返回:
        X ~ belief                         // 从后验抽样，不读真实隐藏状态
        SIMULATE(T.root, X, I, depth=0)
    return 根访问次数最多的合法行动；无完成模拟则返回 argmax π，并记回退

SIMULATE(node, X, I, depth):
    若整场结束: return z_root
    若新节点或达到深度上限:
        安装 π(I)；return V(I)
    a = argmax[Q(node,a) + c·P(node,a)·sqrt(N(node)+1)/(1+N(node,a))]
    在 X 中执行 a，按规则抽样补牌／奖励
    while 未到根玩家决策且未整场结束:
        若轮末: 按规则采样下一轮发牌
        否则: 从 μ(·|I_opp(X)) 抽对手合法行动并执行
        追加根玩家能看到的观察，更新公共历史
    用新增根玩家观察寻找共享子节点
    v = SIMULATE(child, X', I', depth+1)
    更新 N/W/Q；return v
```

首轮比较深度 1、4、8 个我方决策。深度 1 是廉价对照：只看我方行动、对手应答和机会结果，然后用 V 估计余下整场。它可验证价值、对手模型是否有用，再决定树扩展是否值得成本。

所有根合法行动保留非零先验。有限预算不会保证逐一访问全部行动，因此必须记录未访问比例；首版不按 Q 永久删除卖牌数量或交换行动。高分支时先用逐步展开，记录其覆盖代价，再作为单独消融。

树键包含观察而不是完整采样状态；也不能只按当前棋盘合并不同公开历史。搜索中不得针对某个粒子的隐藏牌单独贪心选择我方后续动作。μ 是固定对手模型，不能保证对所有对手稳健，更不保证 Nash 均衡；通过多风格对手池与固定对手交叉评测检查这一限制。

## 7. 训练分四个可验收阶段

**A．数据和表示。** 将已有完整轨迹转成双方 PlayerView、PublicEvent、合法行动、行为动作、终局 z、私有监督标签。按整场 seed 分割训练／开发／最终留出集；同局相邻位置不能跨集合。先训练 π 的行为克隆、V 的 MC 回归、μ 行动预测、B 隐藏牌分类；单独报告不同生成策略的数据，保留真实自然发牌分布。

**B．无搜索策略改进。** 用 fresh on-policy PPO 训练 π，C 提供特权 baseline，V 继续拟合同批整场回报。按“同一个玩家本次决策到下次决策”组织 GAE，gamma=1、lambda=0.95 为起点，避免交替行动者下符号出错。首版可用 lr=1e-4、clip=0.2、梯度范数上限1、最多4个 epoch，KL 超出预登记阈值提前停止当批优化；这些是起始超参。

每个采样批次固定对手池和 actor 版本，例如当前 actor 50%、过去冻结版本40%、轻量规则对手10%。昂贵的1秒搜索对手样本优先从已存日志和有限离线标注取得，训练中若加入搜索对手须单独限定耗时占比、记录其预算。只把本轮当前 actor 实际采样的动作放入 PPO loss，保留其旧 log-prob；历史模型和基线的动作供 μ／辅助学习，不冒充 on-policy 样本。V 在进入此阶段后用当前行为产生的回报重新拟合，避免把旧策略回报当成当前策略的精确价值。先验证特权 critic 相对普通 critic 在相同数据量及时间下是否有益。

**C．冻结网络，测试搜索。** 固定模型、后验和 μ，比较纯策略、深度1估值、单历史树搜索以及旧 `guidedBehavior`。这一阶段才能区分“模型更强”与“搜索给同一个模型带来增益”。1秒是主要评测，固定模拟次数仅用于排查路径和实现差异。

**D．搜索自我对局迭代。** C 确认搜索有收益后，生成根访问分布及整场结果；用 `CE(π_search, πθ) + λv(V-z)^2` 训练公开策略价值网络。μ 继续学习实际搜索代理的行动。每代冻结生成器、记录搜索预算与对手版本。这里使用搜索策略监督，不把树搜索选出的行为动作硬套进以 π 为行为分布的 PPO 比率。是否再做 PPO 是独立阶段，需重新采集 fresh actor 轨迹。

损失分开记录：policy CE／PPO、value Brier或MSE、μ NLL、手牌 NLL、entropy、KL、grad norm。辅助权重先选在开发集，不能凭总 loss 越低就判定升版。

## 8. 1 秒预算与运行路径

计时从收到决策请求起覆盖真实后验更新、编码、推理、模拟、动作解码；历史缓存允许复用，但当次新增事件处理必须计时。初始为输出和最坏一次短批处理预留20ms，实测 p99 后调整；CPU 调度下不能宣称严格实时硬截止。

- 网络导出 FP32 到 C++/Wasm，复用 `tiny_nn.h`；补齐并数值验证 GRU 运算。搜索内每节点不启动 Python，不逐行动做进程 RPC。
- 状态上下文算一次，行动特征批量评分；缓存历史编码与节点策略。只对仍有合法支持的粒子计算 μ，按“历史+假设手牌/奖励”缓存。
- 先测少量代表局面的中位／p95分支数、粒子更新时间、每秒叶子数，再选择32/128/256粒子与深度。不给未经测量的固定吞吐承诺。
- 中途超时且没完成宏转移的模拟丢弃，不回传伪造的0；已完成叶子可回传 V。记录丢弃、纯策略回退、有效模拟数、深度和根覆盖率。
- SwanLab「日志」每10手输出局数、轮次、比分、耗时和回退原因；异步写入有界队列，与搜索计时及决策线程分离。

## 9. 必须通过的验证与消融

信息边界测试：固定某玩家观察，替换未知真实手牌、牌序、奖励分配，π/V 和树键保持一致；固定对手可见信息，改变根玩家未知手牌时 μ 输出不变。粒子变化可影响模拟转移，但不能把隐藏状态塞进策略输入。终局价值在双方视角反号；非终局不同私有观察的 V 不强行要求精确反号。

后验与机会测试：全部粒子满足手牌上限、牌数守恒、公开历史及奖励无放回约束；收市概率用“能收市”和“预测会收市”分别衡量；人工构造小牌池精确枚举对照抽样频率。检查不同世界相同可见历史确实共享节点和统计；真实公开补牌产生正确的观察分支。

模型诊断：隐藏牌校准／NLL、真实对手行动的**后验边缘概率** `sum_j w_j μ(a|I_opp(X_j))` 的 NLL、价值校准、不同印章比分及残局分桶、后验ESS和重建频率。低MSE不代替对局评测。

最小消融顺序：

1. 现有 DMC 与旧搜索留作冻结基线；新公开策略价值模型，无特权 critic。
2. 同设置加入特权 critic，检验训练收益。
3. 固定模型，规则后验 vs 行动似然后验；深度1检验模型和后验收益。
4. 固定模型及后验，深度1 vs 单历史树，检验搜索收益。
5. 独立比较 μ 行动预测与当前 π 充当对手策略，检验对手建模收益。
6. 最后比较搜索自我对局迭代与相同计算预算的无搜索续训。

开发初筛使用新8–16个配对seed；只作排错和淘汰。正式确认冻结一个候选，用另外256个配对seed（512场完整比赛）；以每seed两场的平均胜分为单位，报告20,000次按seed重采样的配对bootstrap近似置信区间，并对双方2:0横扫seed作单侧精确检验。禁止因中途领先而停表或换模型。升版门槛建议：胜率点估计至少53%、单侧95%置信下界超过50%、预登记检验p<0.05，并通过正确性与耗时门槛；达不到即不升版。后续重复训练种子才能判断方法收益是否稳定。

按已完成15场的105.6手／场粗估，若每手耗满1秒，16场约28分钟、128场约3.8小时、512场约15小时；这仅是预算估算。因此先做离线诊断和小样本开发筛选，把大规模1秒对局留给冻结候选。新seed清单在启动前与全部既有训练／评测seed去重登记。

## 10. 实现拆分与优先级

| 顺序 | 建议模块 | 完成判据 |
| --- | --- | --- |
| 1 | `public-events`、`player-view`、轨迹转换器 | 与引擎回放一致；跨隐藏世界输入不变；可正确表达轮末与私有奖励 |
| 2 | `policy-value` learner、μ／B heads、特权critic | 可训练、可导出；纯策略完成比赛；分别记录标签来源及信息字段 |
| 3 | `belief-filter` | 规则支持与小牌池精确解吻合；μ似然更新不重复计证据 |
| 4 | `information-search`（新增，独立于现有八树代码） | 宏转移、历史树键、root采样、叶子价值及截止路径通过测试 |
| 5 | 原生推理与1秒评测入口 | Python/C++输出对齐、计时完整、SwanLab每10手日志、正式配对回放 |
| 6 | 搜索策略训练 | 有真实根访问标签与冻结生成版本，能测到相同模型搜索的增益 |

第一轮投入应优先完成1–2并验收纯策略和价值校准，然后实现深度1原型。已有Q网络及此前7:8、21:27等结果仅作为旧方案证据，不能代替这套新结构的验证。
