# 信息集模型第一阶段试验（运行前计划）

2026-09-24。旧试验保持停止，本目录新实验不替换线上模型。

- 从已完成的旧搜索比赛合法回放，隔一手采样。SHA256(seed) 首字节模 5 为 0 的整组种子进入 dev；其余 train。同种子两座位及不同预算均放同组。
- GRU64 + public state MLP128；行动编码24→32，策略和对手头各160→64→1，整场胜负价值128→64→1。辅助手牌6×8分类。特权 critic 单独监督，不回传 actor；本阶段是离线初始化，不声称 PPO。
- AdamW 3e-4，batch64，10 epochs，seed7241；按 dev 策略 NLL + 价值 MSE 选 checkpoint。
- 首先核验脱敏输入、无放回采样、Python/JS 数值一致、合法行动。再用独立种子51001起，32对换座位比赛检查纯策略 vs normal。
- 搜索完整预算每手1000ms。独立种子52001–52002，两对换座位比赛比较深度1搜索 vs 同模型纯策略；53001–53002比较深度1 vs 旧 guidedBehavior 搜索。属于可行性试验，不作显著棋力结论。
- 每10手输出比分／印章进度到子进程 stdout，SwanLab 父进程直接捕获到日志页。种子不作为网络输入。
- 保留完整可重放动作、搜索吞吐和耗时。先报告瓶颈，再决定后续 PPO 或搜索蒸馏；不因小样本偶然胜率上线。

## 顺序追加：PPO 可行性试验（离线模型 12:52 后、PPO 运行前）

离线模型未通过 normal 门槛。增加独立 PPO 试验，不改动以上冻结模型的搜索对照。初始化使用 epoch9；16 轮×32 新比赛，每轮3遍 PPO，AdamW1e-4，clip0.2，gamma1、lambda0.95、entropy0.01、KL0.02早停。每10局5局当前模型双方、4局历史策略、1局 normal（32局使比例近似）；采样双方策略，只有当前模型行动进入 PPO。特权 critic 对各玩家下一次行动作 GAE；公开价值学习整场 MC 回报。所有旧策略 log-prob 与 Python 重新计算数值核验。固定最终第16轮，不按胜率挑 checkpoint。

训练发牌种子60100–61631（每轮块首32个）。评估新种子54001–54032共64换座位比赛 PPO vs normal，并以同一组新种子补测冻结离线模型，供配对比较。1秒搜索耗时实验与 PPO 训练顺序执行，避免争用计算资源。

实战评估前补齐旧 DMC 对照：固定最终 PPO vs 冻结 DMC738，55001–55032 的32个新配对种子；两者均直接推理，独立于搜索1秒对照。此测试不参与 checkpoint 选择。
