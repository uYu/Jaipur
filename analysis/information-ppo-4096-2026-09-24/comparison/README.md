# PPO144 对照结果

状态：完成。冻结最终第144轮模型，4组各64个新种子、交换座位，共512场完整比赛。全部为直接模型／规则策略落子，未加入树搜索；本结果不代表1秒MCTS表现。

| 候选 | 对手 | 战绩 | 胜率 |
| --- | --- | --- | --- |
| PPO144 | PPO16 | 99:29 | 77.34% |
| PPO144 | normal | 60:68 | 46.88% |
| PPO16 | normal（同一批种子） | 40:88 | 31.25% |
| PPO144 | DMC738 | 27:101 | 21.09% |

## 解释

- 追加4096场后，PPO144明显强于PPO16：64个配对种子中，39组2:0、21组1:1、4组0:2。按种子配对的双侧精确符号检验 p=3.11e-8。
- 对normal，在相同种子上提升15.625个百分点。按种子整组bootstrap 20,000次，提升的95%区间为+2.34至+28.13个百分点。这是匹配种子的比较，不是把两批比赛当成独立样本。
- PPO144对normal接近五五开，但无证据超过normal；其胜率的配对种子bootstrap区间为37.5%–56.25%。
- 对DMC738仍明显落后，27:101；胜率区间约14.06%–28.13%。不能因相对早期PPO的提升而替换已有模型。
- 四组仅对应本次固定检查点及对手，不证明后续增加训练量必然继续改善。未按此次测试挑选检查点，未部署新AI。
