# 原因诊断：训练不足还是算法设计问题

结论：有直接证据说明增加训练量仍有收益，也发现了训练对手安排的具体缺陷。现有实验不能定量拆分两者贡献，不能据此判定PPO路线根本不适用。建议先修正可确认的训练设置，再用等预算分支区分继续训练与设计修改的作用。

## 1. 回顾性检查点曲线

固定5个已保存检查点，对normal使用相同的310001–310032新种子并交换座位。每个64场，共320场；仅用于诊断趋势，不选择检查点、不替代先前128场正式对照。

| PPO轮次 | 累计训练场数 | 胜负 |
| --- | --- | --- |
| 16 | 512 | 13:51 |
| 48 | 1536 | 22:42 |
| 80 | 2560 | 30:34 |
| 112 | 3584 | 29:35 |
| 144 | 4608 | 37:27 |

整体上升，尚没有明确的长期平台证据；80到112存在波动，不能假定单调提升。144在此64场中超过50%，但此前128场为60:68，不能据此宣布超过normal。320场、31165次行动已完整回放核验。见 [原始核验](verification.json)、[运行前诊断配置](plan.json)、[SwanLab日志](https://swanlab.cn/@franzyu/jaipur-dmc/runs/7qp1xnpc)。

训练样本量：PPO16的46243 + 追加323675 = **369918条新鲜强化学习样本**，另有6180条离线初始化训练样本。DMC738为179185（起步）+10009435（到658）+1283774（658到738）=**11472394条**，94464场。DMC约有31倍强化学习样本、20.5倍比赛；两者表示、算法和样本利用方式不同，不能据此推断PPO再训31倍就一定追平。

## 2. 已确认的实现／训练设置不足

### normal对手与座位耦合

`scripts/collect-information.ts` 同时使用 `seat=game%2` 与 `game%10==9` 分配normal。32场批次中normal只出现在9、19、29，全部是座位1。追加4096场中384场normal比赛全部如此，PPO赢101场。两座位虽共享网络并采用相对编码，这仍造成面对固定对手时的发牌／先手训练覆盖不均衡；它对棋力的具体损害需要消融量化。

### 历史对手池只有一个近期快照

每4批覆盖同一个past.json，保留的是更新前一轮模型。没有多年代际快照池；当前与近期历史占90.625%，normal仅9.375%，没有DMC对手。易学到适应自己近期行为的策略，跨对手泛化可能不足。这是机制风险，尚未用修正分支证明因果贡献。

### 行动预测头未学到实际混合对手的全部行为

采集器只保存active actor的行动用于训练，mu与pi在同一批当前actor动作上监督。历史对手／normal的动作没有单独进入mu数据。因此该头主要跟踪自己，尚不等于已校准的外部对手预测器。直接落子不调用mu，不能用此问题单独解释纯策略对DMC的败绩；接入搜索时问题更直接。

### 尚不是完整的搜索训练闭环

没有用搜索访问分布蒸馏训练pi；规则后验存在，但隐藏牌辅助头尚未用于后验重加权。不能把本原型表现直接视为AP-MCTS或PerfectDou论文方法的效果。本轮主对照都是纯策略，MCTS结构不能直接解释纯策略落后。

## 3. 值得排查，但目前不是已证实原因

- **探索收缩**：续训最早16批的平均策略熵1.4802，最后16批0.7294。分布更集中；但日志未按合法行动数归一化，不可仅凭此判断“过早塌缩”。固定局面归一化熵、最大行动概率与采样／贪心对照更有诊断价值。
- **稀疏回报及critic偏差**：平均一场103.08次总行动，只有完整比赛终局给±1。GAE采用gamma1、lambda0.95，50个本方决策前的末端TD残差系数约0.077；中间TD项和critic仍可补偿，不能误说最终奖励被直接折扣掉。critic不准时长期归因可能困难。[GAE原论文](https://arxiv.org/abs/1506.02438)明确讨论用价值估计降低方差但引入偏差的取舍。
- **loss不能直接当棋力**：public V对MC终局回报回归，critic对GAE lambda-return回归，两种MSE不能直接比较。末16批public value MSE约0.806，不构成价值网络已收敛的证明。旧行为dev NLL升高也不能自动称为过拟合或退化。
- **采样与贪心评测差异**：训练按pi抽样，评测argmax；需在同种子下比较两种执行方式后才能判断影响。它不是必然错误。
- **输入／初始化差异**：DMC actor显式输入精确手牌后验边际，新actor依靠GRU及辅助监督学习相关信息，规则后验主要用于搜索。新网络从小规模离线模仿起步，没有继承DMC738的行动价值能力。差距不能全部归因于PPO vs DMC的优化算法。

## 4. 已有检查未见的基础错误

按各自玩家的决策序列计算GAE、整场胜负符号一致、旧log-prob匹配PyTorch/JS、合法行动、信息隔离和终局回放均已有核验。128批没有触发KL早停，平均KL约0.001–0.002；不支持“所有更新都被KL门槛挡住”的解释，但平均KL并不能替代完整梯度／有效更新审计。PPO基本形式参照 [PPO原论文](https://arxiv.org/abs/1707.06347)。

## 5. 建议的最小归因实验（尚未执行）

1. 从同一个144检查点分支，固定相同新增比赛数及训练超参数。
2. A维持原训练设置继续训练；B仅解耦对手与座位，确保每类对手双方覆盖。用于验证座位问题影响。
3. 在座位修正后，另做单快照与多历史快照池对照；是否加入DMC作为训练对手作为再下一项独立变量，不与其他修改混在一起。
4. 使用开发集定期测固定对手学习曲线；最终用预先留出的独立种子确认。至少多个训练随机种子才适合估计算法修改的稳定收益。
5. 纯策略达到可接受基线后，再单独验证mu、V校准与1秒搜索增益；保留原本整场胜负目标，避免同时引入未经验证的分数奖励。

本次按用户请求进行原因分析和回顾性评测，未更改现有训练算法，也未启动新训练。
