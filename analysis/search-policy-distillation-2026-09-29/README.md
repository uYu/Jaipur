# 固定搜索次数的 MCTS 策略蒸馏试验（2026-09-29）

本实验仅训练一个研究用的公开信念行动策略，并将其用作搜索根节点先验。没有续训 DouZero，也没有替换正式网页 AI。

## 数据与模型

- 教师：原版 `guidedBehavior`，每个局面 8 棵树 × 每棵 512 次模拟，共 4096 次；目标为根节点各合法行动的访问分布。固定搜索次数使标签不依赖生成时的机器负载。
- 训练：种子 1001–1020 和 1101–1120，80 场完整对局，1556 个局面。
- 验证：种子 1201–1210，20 场、298 个局面；只用于选检查点。
- 独立测试：种子 1301–1320，40 场、768 个局面；训练和选模均未使用。
- 策略网络：公开信念状态 142 维 + 行动 24 维，166→128→1；按局面归一化后，用搜索访问分布做交叉熵训练。终局价值辅助损失权重为 0；导出的价值头没有训练，也没有接入搜索。第 28 轮的验证交叉熵最低。

完整数据、权重和元数据在 `output/jaipur-search-distill-20260929/`。旧对照为 `analysis/ai-eval-2026-09-23/belief-policy-model.pt`。

## 独立测试结果

| 策略 | 交叉熵，低为好 | 模型首选行动的教师访问份额 | 与教师首选吻合 |
| --- | ---: | ---: | ---: |
| 旧 50 ms 教师策略 | 2.2984 | 29.66% | 48.18% |
| 新 4096 次模拟教师策略 | 2.2506 | 30.54% | 49.61% |

教师自身最高访问份额均值为 39.94%；均匀策略交叉熵为 2.7727。新策略离线指标小幅改善。这里的教师偏好仍不是最优行动的真值。

PyTorch 与编译后的 C++ 在 595 组策略/价值输入上的最大绝对输出差为 2.38×10⁻⁶。价值头未训练，这项数值校验不代表价值预测质量。

## 完整对局

三组均为 10 个独立种子、交换先后手的 20 局，双方每步固定 8×256＝2048 次模拟，脚本逐步验证搜索次数。新旧模型都只提供根节点先验，其余搜索逻辑一致。

| 对照 | 结果 | 双方平均整步耗时 |
| --- | ---: | ---: |
| 新策略 + MCTS 对原版 MCTS，种子 3900009300–9309 | 13:7 | 85.9 / 84.9 ms |
| 旧策略 + MCTS 对原版 MCTS，同种子 | 11:9 | 86.0 / 84.0 ms |
| 新策略 + MCTS 直接对旧策略 + MCTS，独立种子 3900009400–9409 | 10:10 | 85.5 / 85.1 ms |

这些对局支持“新策略可正常接入，耗时基本相同”，但**不支持已比旧策略更强**。20 局无法精确估计小幅胜率差；本轮不升版，也不凭离线交叉熵扩大训练。

## 复现与下一步

`scripts/generate-belief-policy-data.ts` 新增 `--iterations-per-tree 512`；未指定时保留旧的 50 ms 教师。`scripts/train-belief-policy.py` 新增 `--hidden` 和 `--value-weight`，旧默认仍为 32 和 0.25。评测文件 `new-prior-vs-mcts-summary.json`、`old-prior-vs-mcts-summary.json`、`new-vs-old-summary.json` 位于本轮输出目录，逐局记录在同名 `*-games.jsonl`。

若继续此路线，优先增加**不同种子的局面覆盖**与拿货/换牌分歧局面，而非仅继续增加每个局面的模拟次数；并在未参与选模的新种子上做更多配对对局。当前没有自动启动后续训练。
