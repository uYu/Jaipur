# DouZero 根节点先验诊断（2026-09-29）

本实验不训练模型，也不替换网页 AI。持续自我对局已在第 2369 轮中断；最后落盘检查点为 `model-2350.pt`。

## 对局控制

评测使用独立于训练和开发集的种子 3900009000–3900009003，每个种子交换先后手，共 8 局。两侧每步均执行 8 棵树 × 每棵 1024 次模拟；评测脚本验证每次决策的模拟次数。`guidedFullSale` 只在搜索树**根节点**删除少卖牌候选，深层树与模拟策略仍按原规则运行；`douzeroMctsFullSale` 在同一限制下，以固定温度 0.2 的 DouZero Q softmax 与原先验各占 50%。它们是搜索研究配置，不等于修改了完整游戏规则。

| 对照 | 候选胜负 | 平均每步耗时 |
| --- | ---: | ---: |
| 第 700 轮 DouZero 根先验 + 原版 MCTS，对原版 MCTS | 4:4 | 386 / 392 ms |
| 仅限制根节点少卖的 MCTS，对原版 MCTS | 3:5 | 336 / 1204 ms* |
| 第 700 轮 DouZero 根先验 + 限制根节点少卖的 MCTS，对相同限制的 MCTS | 2:6 | 330 / 325 ms |

\* 原版侧有一次异常的 352 秒决策，拉高了均值；这项耗时不宜用于性能判断。每项仅 8 局，不足以估计小幅胜率差。

原始汇总分别位于 `output/jaipur-model700-eval-20260929/hybrid-vs-mcts-summary.json`、`fullsale-root-vs-mcts-summary.json`、`hybrid-fullsale-vs-fullsale-summary.json`；逐局事件在同目录的 `*-games.jsonl`。

## 逐局面排序

从此前两组不同模型与 MCTS 的完整对局中等距抽取 128 个局面，重放公共历史。原版 MCTS 每局面运行 8 × 512 次模拟并记录每个合法根行动的访问份额；第 700 和 2350 轮模型在**相同局面**评分，只在模型训练过的整组卖牌候选中比较行动。局面在同一对局内相关，不能当作 128 个独立对局。

| 指标 | 第 700 轮 | 第 2350 轮 |
| --- | ---: | ---: |
| 模型首选 = MCTS 在整组卖牌候选中的首选 | 53/128 = 41.4% | 49/128 = 38.3% |
| 模型首选承接 MCTS 访问份额，均值 | 24.3% | 23.9% |
| MCTS 首选行动的访问份额，均值 | 34.2% | 34.2% |
| 搜索首选为拿货时的精确吻合 | 13/37 | 13/37 |
| 搜索首选为换牌时的精确吻合 | 7/32 | 7/32 |
| 搜索首选为卖牌时的精确吻合 | 19/38 | 17/38 |
| 搜索首选为骆驼时的精确吻合 | 14/21 | 12/21 |

模型可选行动上的随机首选吻合期望约 9.5%。原版 MCTS 首选少卖牌为 0/128；少卖牌占根节点访问份额均值 3.6%。因此在此样本里，少卖牌分布外问题确实存在，却不足以解释大部分先验与搜索分歧。访问份额仅代表当前搜索器的偏好，不是动作最优性的真值。

完整记录：`output/jaipur-model700-eval-20260929/prior-audit-128.json`。

## 决策

暂不继续同配置 DMC 自我对局，也不把当前先验接入正式 AI。下一项实验应优先从上述拿货和换牌分歧局面构造小而独立的教师集：提高搜索预算、保存访问分布和具体行动、按种子隔离训练与验证，再与旧的 50 ms 教师策略实验比较。仓库既有 `analysis/ai-eval-2026-09-23/belief-policy-followup.md` 记录了 1,556 个训练局面、50 ms 教师的策略蒸馏，在 20 局实战中为 8:12；直接重复该配置缺乏依据。只有离线排序和独立完整对局两项同时改善，才考虑继续训练并扩大样本。
