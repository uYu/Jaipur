禁止少卖本身没有解释掉分层版的巨大退化；硬选择类型之外，分层版具体行动头也明显弱于相近样本量的单头模型。独立类型头、换入头与具体行动头分别回归同一终局标签，训练信号竞争且早期选择会改变后续数据分布，这是代码和现象支持的**机制假说**，还不能把每个头的贡献精确分离。

本次已停止长期分层训练。替代对照 `output/jaipur-flat-fullsale-10m-20260929` 使用原版单头 Q 网络与整组卖出候选，从零训练；它将单独检验卖牌限制的长期影响。SwanLab 新运行中 `selfplay/avg_game_turns` 使用已完成比赛的样本数除以完成场次；完成场次、截断场次和总行动数继续留在本地 `training.jsonl`。

替代对照第 50 轮累计 766,588 样本，固定开发集为 27:37、截断 0；原版第 50 轮累计 691,967 样本时为 29:35，失败的分层版第 50 轮累计 852,564 样本时为 0:64。这是早期开发集结果，不能据此断定两个单头版本最终强度相同。替代对照正朝预设的 1,000 万样本目标继续训练。
