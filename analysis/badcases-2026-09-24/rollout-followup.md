# Rollout 诊断与终局应对候选修正

## 查到了什么

并没有证据支持“这些败局都是神经网络不会卖牌”。guided 使用训练过的线性模型；新 beliefRoot 也继续使用它做 rollout，新网络只用于根节点先验。旧 neural 才使用神经网络 rollout。

对六个固定位置的每个合法动作，以相同随机种子从公开观测抽取 128 个世界，再检查对手是否存在立即获胜的卖牌。这个检查不读取存档里的真实对手奖励或隐藏手牌。

下表只列历史实际选择的动作。分母是存在获胜卖牌的模拟世界数；两个模型都使用相同的探索随机种子。

| 局面      | 存在立即获胜应对 | 线性模型关闭探索时漏选 | 线性模型开启 10% 探索时漏选 | 神经网络开启 10% 探索时漏选 |
| --------- | ---------------: | ---------------------: | --------------------------: | --------------------------: |
| 3309 / 84 |           13/128 |                      0 |                           1 |                           1 |
| 2806 / 45 |          124/128 |                      0 |                          16 |                          16 |
| 1309 / 79 |           38/128 |                      0 |                           3 |                           3 |
| 1306 / 80 |           22/128 |                      0 |                           5 |                           5 |
| 3701 / 66 |            0/128 |                      — |                           — |                           — |
| 3801 / 83 |            0/128 |                      — |                           — |                           — |

这些是诊断抽样次数，不能当成实际搜索漏选率。线性模型在六个局面的全部候选动作诊断中，关闭探索时均未漏选立即获胜的卖牌。探索发生在模型选动作之前，因此会直接绕过正确的终局判断。

同时，手牌全部已知仍有隐藏奖励分数。3309 的历史实际隐藏分数足以惩罚换牌，但大多数诊断世界中对手卖白银不能立即获胜。之前仅凭这份历史结局将换牌定性为明显错误，证据过强；必须考虑当时的信息和其他应对。

进一步用与搜索相同的抽样序列检查：3309 的前八个世界中，立即获胜应对出现 **0 次**，128 个世界中出现 13 次。这解释了为什么延长每棵树的搜索时间也没有修正这手换牌：八个世界固定后，增加搜索深度不会补上缺失的隐藏奖励组合。2806、1309、1306 对应的前八个世界分别有 8、3、2 个危险世界。这里缺失的是奖励分数组合，不能直接归到手牌后验精度。

按当前模型对隐藏奖励的均匀抽样假设，3309 还可直接枚举公开信息允许的奖励组合：自己已拿走两枚 2 分的三张奖励，因此剩余三张奖励是 `[1,1,2,3,3]`，四张奖励是 `[4,4,5,5,6,6]`。对手已有一枚三张奖励、一枚四张奖励，卖三白银再抽一枚三张奖励。120 个按筹码身份等可能的有序组合中，16 个让对手达到至少 60 分并获胜，概率为 **13.33%**。在独立抽样近似下，八次全部漏掉的概率约 **31.83%**。这是能立即收市且获胜的概率，不是整轮最终胜率，也不证明换牌一定劣于卖香料。

## 做了什么修改

新增实验开关 `terminal_tactics`，默认关闭，未修改浏览器的已构建 Wasm：

1. rollout 在随机探索之前枚举能够收市的合法卖牌，若有直接获胜的结果，立即使用引擎结算结果。
2. 树中执行一个候选动作后，也检查下一位玩家是否可一手卖牌获胜。若可以，直接回传该终局，无需依赖模拟策略或继续访问该应对。
3. 检查使用同一模拟世界中的手牌、筹码和隐藏奖励；没有把真实存档信息注入搜索。它只证明该模拟世界中的结果，不证明公开信息下必胜。
4. 不强制接受输掉的收市，不禁止交换或拆套，也不按手牌货值伪造终局奖励。

修改位于 `cpp/mcts.hpp`，研究入口和基准新增 `tactical` 配置。增加双玩家视角、驼队奖励、同分判定、拒绝失败收市和 rollout 终局处理的测试；完整 native 测试通过（1,383 个合法行动枚举局面与原有决策回归）。

## 1 秒固定局面消融

所有模式使用相同的公开观测、beta=0.75 手牌分布和八个模拟世界。每个位置每种配置跑一次，保存全部根节点的归一化访问占比和条件平均结果。时间限制为搜索本身 1 秒；这些位置测试不计外部观测编码时间。完整比赛的计时另行包含观测耗时。

| 局面 | 原 guided         | 终局应对修正           |
| ---- | ----------------- | ---------------------- |
| 3309 | 香料 + 骆驼换两钻 | 同一动作，未改变       |
| 2806 | 拿骆驼            | 卖一皮革，符合人工候选 |
| 1309 | 卖一皮革          | 卖两皮革，符合人工候选 |
| 1306 | 卖两白银          | 仍卖两白银             |
| 3701 | 交换              | 仍交换，改变交换组合   |
| 3801 | 拆白银套换香料    | 同一动作，未改变       |

其他消融没有形成“只换掉 rollout 就全部修好”的结果：1309 换随机 rollout 或神经 rollout 也改卖两皮革；3801 关闭训练先验后改卖三白银。3701 所有配置仍选交换。这些是单次局面结果，不能据此宣称哪种配置更强。

2806 还直接暴露出根节点汇总的问题：原 guided 选择拿骆驼，访问占比 0.2733、条件平均胜负值约 -0.9991；卖皮革访问占比 0.2692、条件平均值约 -0.0733。最终按跨树访问占比选动作，把前者排在前面。条件平均值来自各动作被访问时的世界分布，也不能简单当成可直接比较的无偏胜率；但这个现象说明需要继续检查失败世界的访问票数如何影响汇总。

## 复现与数据

- `node scripts/build-ai-research.mjs`
- `node --experimental-strip-types scripts/audit-rollout.ts audit`：公开观测下的一手应对审计。
- `node --experimental-strip-types scripts/audit-rollout.ts search 1000`：五种配置的局面消融。
- `rollout-audit.jsonl`、`search-ablation-1s.jsonl` 保存本次输出。
- 完整对局使用 `scripts/benchmark-native.ts tactical guidedBehavior`，每个种子交换双方座位；`tactical-*-games.jsonl` 保存完整行动，`tactical-*-result.json` 包含逐局结果和最终统计。

固定局面改善不足以升版；完整比赛结果及预算检查见下节。

## 完整对局初步结果

两边都使用 beta=0.75 公开手牌后验、旧线性先验和 rollout、八个世界；唯一配置差别是候选开启 `terminal_tactics`。不使用新 beliefRoot 网络。种子为新种子，均交换先后手，按整场先赢两轮的胜负计数。

| 预算  | 种子      | 场数 | 候选 : guidedBehavior |
| ----- | --------- | ---: | --------------------: |
| 50 ms | 4101–4110 |   20 |                  14:6 |
| 1 s   | 4201–4202 |    4 |                   1:3 |
| 2 s   | 4301      |    2 |                   1:1 |

50 ms 下，按种子配对是五组双胜、一组双负、四组各胜一场。双方平均完整决策耗时约 45.5 ms；最大耗时分别约 69 ms 和 108 ms，后者含一次 91 ms 的观测计算，不能宣称所有行动都严格满足 50 ms。

1 s 下，候选最大完整决策耗时约 999.95 ms，基线约 1047.05 ms。没有将这些超时行动剔除。这个小样本不支持宣称实力提升；50 ms 的胜绩没有在 1 s 复现。

新 1 s 败局也已回放（`tactical-1s-audit.json`）：候选在输轮中有六个对手下一手卖牌收市的位置，均不能通过改卖一手、保持记录中的对手卖牌而翻盘。仍存在三个交换拆套筛选片段，但不据此判为三次错误。终局战术修正没有解决更早形成的分差。

2 s 下双方平均完整决策耗时分别约 1847.50 ms、1867.94 ms；最大值约 2022.39 ms、2005.14 ms。有轻微超预算，全部保留计入成绩。没有同时运行其他对局实验，但未做机器独占或系统负载控制。

**结论：不升版。** 完整配对共 26 场，不同预算分开报告；长预算样本小，既不能证明候选整体更强，也不足以可靠断言它整体更弱。它修正了一个明确的模拟行为，并改善两个固定位置，但未通过 1 s 和更长预算的实战提升验证。实验开关保持默认关闭，浏览器 Wasm 不变。

接下来的证据指向固定八个世界的奖励覆盖，以及根节点跨世界汇总；不应继续仅凭 MSE 重训网络，也不应因为局部修正奏效就增加“总要卖牌”等规则。本次到此收束，没有继续追加训练或对局。

最终验证：native 测试通过，TypeScript 构建检查通过，`git diff --check` 通过。新增搜索层回归明确验证：自己直接获胜的卖牌回传 +1；拿牌后让对手立即获胜的分支回传 -1。`evaluation-summary.json` 汇集三个预算的完整统计。
