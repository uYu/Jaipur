# JAIPUR · 粉城商事

仿照相邻 `scout` 项目的 React + TypeScript 分层结构与中文交互，实现的斋普尔双人桌游。你与本地 AI 商人米拉对弈，率先获得两枚卓越印章取胜。无需账号、后端或模型 API。

## 运行

Node.js 22.13+：

```bash
npm ci
npm run dev
```

默认地址为 http://127.0.0.1:5173。指定端口可使用 `npm run dev -- --port 5174`。

```bash
npm test                    # 规则、信息隔离、存档和完整比赛
npm run simulate -- 100 hard # 100 场完整困难档 AI 对局
npm run build               # TypeScript 检查与生产构建
npm run preview             # 本地预览生产构建
```

Docker 部署：

```bash
docker-compose up
# http://localhost:8204
# 修改端口：JAIPUR_PORT=8080 docker-compose up
```

`docker-compose up` 会自动构建当前源码（复用构建缓存）并启动服务，无需 `--build`。也支持 `docker compose up`。

`dist/` 可交给任意静态服务器，支持子目录部署。图片为本地原创 SVG，无外部字体、图片或 API 请求。首次打开需要 HTTP 服务；未提供离线缓存 Service Worker，不支持双击 HTML 文件直接运行。

## 完整流程

- 中文主菜单、新比赛设置、继续比赛、规则、三档 AI、三档速度。
- 55 张牌与完整货物筹码、随机奖励筹码；开局保留三头市场骆驼、各发五张牌。
- 拿取单张货物、收走全部骆驼、至少两张的等量交换、单种货物批量出售。
- 7 张手牌上限，驼队独立；交换不能同时收付同类货物，不能通过交换获取骆驼。
- 钻石、黄金、白银至少两张起售；出售三／四／五张及以上获得对应奖励。
- 三类货物筹码耗尽或无法补满市场时结算。骆驼多数奖励 5 卢比，同数无人获得。
- 同分依次比较奖励筹码枚数、货物筹码枚数。完全相同时不颁印章，轮换先手加赛，这是规则书未明示极端平局的实现约定。
- 上轮输家先手；先获得两枚印章者获胜。最后一段行动动画结束后，自动在屏幕中央弹出本轮胜者、双方得分与印章结果，支持直接开始下一轮。整场结束有独立醒目提示、再来一场和返回菜单按钮；收起后牌桌顶部保留结算入口。逐轮战绩可展开查看，手机适配并支持键盘关闭。
- 对手手牌、驼队数量和奖励面值隐藏；对手公开货物收入可见。
- 无行动模式切换：点击市场货物拿取，点击同类手牌出售，两边选牌自动组成交换。点击市场骆驼选中全部；点击自己的驼队图案或加减按钮指定付出数量。再次点击取消，底部预览后确认。交换可任意顺序选牌。
- 开局从牌堆向双方发牌。每次行动直接在牌桌上移动卡牌：市场到手牌、手牌到售卖区、交换双向移动、牌堆补牌到市场并翻面，出售筹码从各自位置逐枚飞出，并排落入卖家收入区；分数旁保留上笔收入的每枚面值，刷新和回放也可查看。没有交易弹窗。对手收到的牌翻成牌背，奖励面值隐藏。展示结束后才允许下一回合；暂停、规则和日志会暂停展示计时，减少动态效果设置下改为静态展示。
- 暂停、规则、日志、菜单会终止 AI Worker；恢复后按当前状态重新计算。
- 桌面双栏牌桌；手机顶部吸附紧凑筹码栏，显示六类剩余数量、下一枚价值、奖励余量与售罄进度，完整筹码明细点开即看。滚动查看手牌时无需翻到页面底部查筹码。键盘可操作、弹窗焦点约束、减少动态效果支持。

## 存档与回放

每次**已提交行动**自动保存到 localStorage，刷新后由菜单继续；尚未确认的选牌不保存。新比赛会替换当前存档，开局设置页有提示。设置中可导出 JSON 或导入备份；导入按种子和完整行动序列逐步重放验证，损坏文件不会替换当前比赛。保存失败显示备份提示。

回放支持播放／暂停、单步和拖动进度，仅展示当时玩家可见信息，不启动 AI，也不写回比赛。难度偏好与 AI 行动速度独立保存在此浏览器。

## AI

AI 在 Web Worker 中执行，仅接收自己的手牌、驼队、市场、公开弃牌与筹码、对手手牌数量和牌堆剩余数量。不会接收对手真实手牌、对手秘密奖励、牌堆顺序或洗牌种子。

- 轻松：对合法行动加入较大随机扰动。
- 普通：穷举合法行动，评估手牌成组潜力、可售价值、批量奖励、驼队边际价值和交换给对手的收益。
- 困难：在普通估值基础上增加珍贵货物竞争、尾盘变现和结束本轮后的残余手牌成本，减少随机扰动。

三档都是本地启发式策略；困难档不是神经网络、MCTS 或深度搜索，也不声称达到专家水平。相同观察下选择可复现。

## 代码

```text
src/game/types.ts        牌、行动、状态与存档类型
src/game/data.ts         牌堆、筹码、标签和确定性随机数
src/game/engine.ts       不可变规则引擎、合法行动和结算
src/game/ai.ts           隔离观察与 AI 评估
src/game/ai.worker.ts    后台 AI 入口
src/game/storage.ts      行动重放、导入验证、导出
src/game/preferences.ts 本地设置
src/components/Art.tsx  原创宫殿与货物 SVG
src/components/Card.tsx 卡牌组件
src/components/Rules.tsx 中文规则
src/App.tsx             菜单、牌桌、选择交互与 Worker 生命周期
src/style.css           响应式布局
scripts/simulate.ts      批量完整比赛
```

## 验证记录

- 27 项自动测试通过，其中完整比赛测试覆盖三档各 12 场，共 36 场。
- 每步检查 55 张牌、38 枚货物筹码、18 枚奖励筹码守恒及手牌限制；终局状态与存档重放一致。
- 额外 100 场困难档完整比赛通过，平均 109.8 次行动，最多 148 次。
- 浏览器实测新比赛、收取骆驼、AI 接续、货物与骆驼混合交换、出售和刷新恢复；检查桌面与 390px 手机布局。
